# Review codebase

Scripts and data behind the paper.

```
scripts/   code used for the models, screening and DFT
data/      the archived inputs/outputs behind every reported number
```

## How to read the numbers

`data/numbers.json` holds every reported value. Each entry is computed from the
CSVs in `data/` by `scripts/validate_numbers.py`:

```bash
python3 scripts/validate_numbers.py        # rewrites data/numbers.json
```

## Scripts

**Models** — `build_glattice_data.py` (builds G_lattice inputs, fixed
`a_ref = 5.0 Å`), `train_glattice_alignn.py`, `train_xgb_glattice.py`,
`train_mlatabc.py` (baselines), `eval_glattice.py`, `prepare_alignn_data.py`.

**Screening** — `prototypes.py`, `screen_one.py` (per-candidate descriptors),
`run_production.py` → `rank_production.py` → `shortlist_production.py`
(the 4,976 → 25 → 10 → 9 funnel).

**DFT** — `gen_vcrelax.py`, `gen_elastic.py`, `gen_verify.py` (QE inputs),
`final_qc.py` (stress→Cij, Born criteria, magnetic-branch check),
`fit_eos.py` (Birch–Murnaghan + QC gate), `fit_elastic.py`,
`make_master.py`, `plot_parity.py`, `plot_elastic.py`,
`build_final_package.py`. Sign/strain conventions are in `DEFORMATIONS.md`.

## Data

| file | what it is |
|---|---|
| `numbers.json` | every reported value (generated) |
| `retrospective_v2_exact.csv` / `_aa.csv` | A–B (325) and A–A (87) matched structures |
| `glattice_splits.json` | composition-disjoint + random splits |
| `glattice_summary_{disjoint,random}.json` | G_lattice benchmark metrics |
| `framework_run_dedup.csv` | generated candidate pool (4,976) |
| `production_run.csv` / `_shortlist.csv` / `_ranked.csv` | GNN predictions, shortlist, ranking |
| `gbulk_test_predictions.csv`, `alignn_ehull_preds.npz` | held-out G_bulk / G_hull predictions |
| `hull_gpu80_test_predictions.csv` | held-out G_hull |
| `mp_snapshot_slim.csv`, `jarvis_shortlist_check.json` | reference data for matching/screening |
| `final_qc.json`, `eos_fits.json`, `master_dft_validation.csv` | DFT QC / EOS fits / combined table |
| `FINAL_RESULTS.csv` | final DFT elastic + EOS results |
| `atomic_radii.json` | radii used by the `a_guess` baseline |
| `candidates_info/` | relaxed cell, pseudos and magnetic state per DFT candidate |
| `energy_check/` | raw QE outputs for the two disputed cases (NiOs, RuO) |

Model checkpoints and the full raw Quantum ESPRESSO output tree are not included
(multi-hundred MB); checkpoints are regenerated by the training scripts and raw
outputs by the `gen_*.py` scripts above.

## Environment

Analysis scripts need numpy, scipy and pandas.
Training and some upstream scripts need the project's `alignn` conda env
(torch, alignn, pymatgen, matminer, jarvis-tools).
